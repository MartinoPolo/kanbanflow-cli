# API Documentation

## Delete attachment

### Description

Deletes an attachment from a task.

### Request format

curl -X DELETE https://kanbanflow.com/api/v1/tasks/<TASK\_ID>/attachments/<ATTACHMENT\_ID>

### Example request

curl -X DELETE https://kanbanflow.com/api/v1/tasks/T3s6UGyzY/attachments/Aks4VwyRB

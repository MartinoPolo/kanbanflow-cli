## Zapier

Zapier lets you connect the web apps you use. You can easily automate tedious tasks with so called **Zaps**. Zaps are automations created using **Triggers** and **Actions**.

Please try it out and let us know about your experience. We are eager to cover new use cases.

### Get started

First, if you do not have a Zapier account already, sign up for a new one here: [Sign up for Zapier](https://zapier.com/sign-up)

Next, you need to create an API token for your board. The token is used for authentication when connecting KanbanFlow to Zapier. To generate a new token, close this dialog and click on **Add API token**. The generated **Secret token** is what you will enter in Zapier. Now you are ready to set up your first Zap! Head over to [Zapier](https://zapier.com), sign in and click on **Make a New Zap**.

For more detailed information, see the [KanbanFlow integrations page on Zapier](https://zapier.com/apps/kanbanflow/integrations).

### Triggers

1.  **New Task** – Triggers when a new task is created
2.  **Task Moved** – Triggers when a task is moved between columns or swimlanes

### Actions

1.  **Create Task** – Adds a new task in a specific column on the board

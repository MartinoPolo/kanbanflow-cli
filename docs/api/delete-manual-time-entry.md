## Delete manual time entry

### Description

Delete a manual time entry.

### Request format

curl -X DELETE https://kanbanflow.com/api/v1/tasks/<TASK\_ID>/manual-time-entries/<MANUAL\_TIME\_ENTRY\_ID>

### Example request

curl -X DELETE https://kanbanflow.com/api/v1/tasks/T3s6UGyzY/manual-time-entries/EyS84FdLk

# API Documentation

* * *

## Delete comment

### Description

Deletes a comment from a task.

### Request format

curl -X DELETE https://kanbanflow.com/api/v1/tasks/<TASK\_ID>/comments/<COMMENT\_ID>

### Example request

curl -X DELETE https://kanbanflow.com/api/v1/tasks/T3s6UGyzY/comments/C3VJU6yeb

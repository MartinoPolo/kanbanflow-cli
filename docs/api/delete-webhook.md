# API Documentation

## Delete webhook

### Description

Delete an existing webhook.

### Request format

curl -X DELETE https://kanbanflow.com/api/v1/webhooks/<WEBHOOK\_ID>

### Example request

curl -X DELETE https://kanbanflow.com/api/v1/webhooks/W5hfpsT5

## Delete date

### Description

Delete a date by its targetColumnId.

### Request format

curl -X DELETE https://kanbanflow.com/api/v1/tasks/<TASK\_ID>/dates/by-target-column-id/<COLUMN\_ID>

### Example request

curl -X DELETE https://kanbanflow.com/api/v1/tasks/T3s6UGyzY/dates/by-target-column-id/COxkPjd0wra4

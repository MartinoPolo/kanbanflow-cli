## Delete task

### Description

Delete a task.

### Request format

curl -X DELETE https://kanbanflow.com/api/v1/tasks/<TASK\_ID>

### Example request

curl -X DELETE https://kanbanflow.com/api/v1/tasks/T3s6UGyzY

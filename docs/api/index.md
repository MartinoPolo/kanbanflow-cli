# API Documentation

* * *

## Welcome to the KanbanFlow API

This documentation will help you get started integrating KanbanFlow with external systems. Use the menu on the left to explore the available endpoints and features.

### About the code examples

Most examples in this documentation use **curl** to demonstrate how the API works. **Curl** is freely available on most platforms and can be downloaded [here](https://curl.se). However, **curl** is not required to use the API. Any client or server library capable of sending HTTP requests can be used to communicate with the API.

Instructions for authenticating with the API are provided in the [Authentication](/api-docs/authentication) section. To keep the examples concise, authentication details are not repeated elsewhere in the documentation.

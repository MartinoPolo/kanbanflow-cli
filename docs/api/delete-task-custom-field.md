# API Documentation

## Delete custom field

### Description

Deletes a custom field value from a task.

### Request format

curl -X DELETE https://kanbanflow.com/api/v1/tasks/<TASK\_ID>/custom-fields/<CUSTOM\_FIELD\_ID>

### Example request

curl -X DELETE https://kanbanflow.com/api/v1/tasks/7HPu4D9Q/custom-fields/g3aB3m
